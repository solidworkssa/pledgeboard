# PledgeBoard

Community pledge tracker for crowdfunding.

## Features
- Multi-chain support (Base & Stacks)
- Secure Contract Logic
- React/Next.js Frontend

## Contracts
- Base: `contracts/base/src/PledgeBoard.sol`
- Stacks: `contracts/stacks/contracts/pledgeboard.clar`

## Setup
```bash
pnpm install
pnpm dev
```
